# Vaero 0.0.1

This pre-release introduces experimental single-file encryption with recovery
phrases, authenticated verification, transactional output, and container
inspection. Recovery-phrase files created with `--phrase-out` have Windows ACL
inheritance removed before secret bytes are written and grant access to the
current user's SID. Windows-managed explicit SYSTEM or Administrators entries
may remain.

The cryptographic container format has not received independent review, and
archive and compression formats are not implemented. Do not use this release
to protect the only copy of data.

Supported platform: 64-bit Windows. Verify downloads with:

```powershell
Get-FileHash -Algorithm SHA256 ./vaero-0.0.1-windows-x86_64.exe
Get-Content ./SHA256SUMS.txt
```
