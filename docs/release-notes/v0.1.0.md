# Vaero 0.1.0

This development release establishes the Rust workspace, safe archive-path validation primitive, CLI shell, test and coverage gates, Windows packaging, dependency policy, and automated nightly/release workflows.

The cryptographic and archive formats are not yet stable and this release must not be used to protect the only copy of data.

Supported platform: 64-bit Windows. Verify downloads with:

```powershell
Get-FileHash -Algorithm SHA256 ./vaero-0.1.0-windows-x86_64.exe
Get-Content ./SHA256SUMS.txt
```
